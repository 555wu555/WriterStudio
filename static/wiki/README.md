# WriterStudio · Code Wiki

WriterStudio 是一款面向中文小说作者的**桌面写作工具**，使用 **C++20 + Qt 6 Widgets** 编写，运行于 Windows。项目由作者本人以"学习驱动"的方式从零手写，目前已完成离线写作全流程，并内置了**AI 行内短语补全**能力（支持本地 Ollama 与 OpenAI 兼容云端服务双通道）。

## 核心特性

- **作品库**：多作品管理、归档/恢复、整本 TXT 导入导出、章节统计
- **写作页**：多作品标签工作区、章节列表（拖拽排序）、自动保存 + `.bak` 上一版备份、专注模式、`@` 引用提及
- **AI 行内建议**：光标停顿后自动请求"接在光标后的短语"，Tab 采纳、Esc 拒绝；本地 Ollama 与云端 Chat Completions 双路由
- **作品设定**：核心设想、大纲、写作约定（视角/时态/风格/节奏/约束），含全局约定回退规则
- **人物与世界资料**：统一的 Entity 模型（人物/地点/组织/物件）+ 双向关系
- **关系图谱**：类 Obsidian 的可交互力导向圆点图，弹簧物理动画、搜索定位

## 三分钟上手

```bash
# 1. 环境要求：Windows + Qt 6.5.3 (MinGW 64-bit) + CMake ≥ 4.1 + C++20 编译器
# 2. 配置时指定本机 Qt 路径，无需修改项目源码
cmake -S . -B cmake-build-debug -DCMAKE_BUILD_TYPE=Debug -DCMAKE_PREFIX_PATH="<Qt 安装目录>/6.5.3/mingw_64"
cmake --build cmake-build-debug

# 3. 运行
./cmake-build-debug/write.exe
```

- 新用户的作品数据默认存放在 Windows 用户应用数据目录；旧开发目录若已有作品或归档会继续使用原位置（可在设置页迁移）。
- 本地 AI：启动 [Ollama](https://ollama.com) 后在"设置 → 模型与提示"中配置。
- 云端 AI：在设置页填入 DeepSeek / 阿里云百炼 / OpenAI 兼容接口与 API Key。
