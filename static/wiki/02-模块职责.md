# 02 · 模块职责

应用被组织为"主窗口 + 五个工作页 + 两类支撑模块（AI 服务、存储）"。本文按职责边界逐一说明；AI 部分仅列概要，详见 [03-AI行内建议子系统](03-AI行内建议子系统.md)。

## 入口与主窗口

### [main.cpp](../../main.cpp)

- 创建 `QApplication`，设置应用名 `WriterStudio` 与图标。
- 调用 `DataRootStore::load()` 确定作品库根目录（优先使用 QSettings；旧目录有数据时兼容旧目录，新用户使用系统应用数据目录）。
- 确保 `<数据根>/projects` 存在且可写；失败时允许重新选择目录，然后构造 `MainWin(projectsPath)` 进入事件循环。

### [MainWin](../../MainWin.h)（主窗口）

- 布局：水平 `QSplitter` = 左侧导航栏（5 个按钮的 `QButtonGroup`）+ 右侧 `QStackedWidget`（5 个工作页）。
- 页面顺序对应 `funIcons = {"作品库","写作","作品设定","关系图谱","设置"}`。
- 职责：
  - **跨页协调中枢**：把当前作品 ID 分发给设定页与图谱页；把 Paper 的"打开作品"请求转给 `WriterWorkspace`。
  - **模型状态徽标**：右上角小圆点显示当前 AI 模型可用性（`pending/available/error/unknown`），汇总 `Writer` 与 `Setter` 的 `modelAvailabilityChanged` 信号。
  - **专注模式**：F11 进入（隐藏左导航、记住并恢复 splitter 状态），Esc 退出。
  - **作者身份**：导航底部的头像与笔名（来自 Setter 的全局作者设置）。
  - **退出保护**：`closeEvent` 依次询问 `designerPage->confirmLeave()` 与 `writerWorkspace_->confirmCloseAll()`。
- 关键函数：`setUi()`（装配全部页面与信号）、`selectModelIdentity()`、`setModelAvailability()`、`setFocusMode()`。

## 五个工作页（WorkPlaces）

### 1. 作品库 [Paper](../../WorkPlaces/workingPaper/Paper.h)（workingPaper/）

- 左列表（`ProjectListDelegate` 自绘卡片）+ 右详情面板；空状态引导页。
- 职责：新建/编辑作品（复用 [CreateProjectDialog](../../models/dialogs/CreateProjectDialog.h)）、双击进入写作、删除（**移入 archive 而非真删**，见 [ArchiveDialog](../../WorkPlaces/workingPaper/ArchiveDialog.h)）、归档恢复、统计章节数与字数。
- 导入导出：
  - **整本 TXT 导出**：`WriterStudio-TXT/1` 文件头（书名/作者/章节数/简介）+ 按序章节。
  - **整本 TXT 导入**：[DocumentImporter](../../storage/DocumentAbout/DocumentImporter.h) 解析 → [ImportPreviewDialog](../../WorkPlaces/workingPaper/ImportPreviewDialog.h) 预览确认 → 创建作品与章节文件。
- 信号出口：`openProjectRequested`、`archiveProjectRequested`、`projectInfoChanged` 等。

### 2. 写作页 WriterWorkspace + Writer + Editor（WritePaper/）

三层嵌套，职责严格分层：

- [**WriterWorkspace**](../../WorkPlaces/WritePaper/WriterWorkspace/WriterWorkspace.h)：多作品标签容器。一个作品 = 一个 `QTabWidget` 标签页 = 一个 `Writer` 实例（`openedProjects_` 哈希管理）；`TabCloseButton` 提供标签关闭按钮；负责把"行内建议开关/专注模式/模型可用性"等事件在 MainWin 与各 Writer 之间转发。
- [**Writer**](../../WorkPlaces/WritePaper/Writer.h)：单作品写作页，最大的业务类。职责：
  - 章节 CRUD：新建、删除、改标题、拖拽排序（[ChapterListWidget](../../WorkPlaces/WritePaper/Writer.h) 重写 `startDrag`）、切章前未保存确认。
  - 保存体系：2 秒延迟自动保存 + Ctrl+S + 保存状态灯（中性/修改/已保存/警告/错误）+ `.bak` 上一版预览恢复。
  - 单章 TXT 导入导出。
  - **资料引用面板**：从 `entities.json` 搜索资料、`@` 触发提及补全（`mentionList_`）、一键插入实体名称；引用面板与正文通过 `refreshReferences()/clearReferences()` 同步。
  - **AI 行内建议调度**：持有 `suggestionService_`（`RoutedGenerationService`）、防抖定时器、请求快照校验——见 [03](03-AI行内建议子系统.md)。
- [**Editor**](../../WorkPlaces/WritePaper/Writer.h)（继承 QTextEdit）：纯编辑器职责，含 AI 建议的**绘制与按键处理**：
  - `showInlineSuggestion()/clearInlineSuggestion()`：用 `QTextLayout` 在光标后排版灰色幽灵文本（跨行、自动滚动腾位）。
  - `keyPressEvent()`：Tab 采纳建议插入正文；Esc 或其他按键清除。
  - `inputMethodEvent()`：跟踪中文输入法组词状态 `composing_`，组词期间不出建议，提交后发 `compositionFinished`。
  - Ctrl+滚轮缩放字号；140% 行距；正文末尾预留滚动空间。

### 3. 作品设定页 [designer](../../WorkPlaces/DesignPaper/designer.h)（DesignPaper/）

- 三区切换（`sectionStack_`）：故事大纲（核心设想 + 自由大纲）、写作约定（视角/时态/风格/节奏/约束五项表单）、人物与世界（`entityList_` + 过滤下拉 + 详情页）。
- 职责：[SetupStore](../../storage/SetUp/SetupStore.h) 读写 `setup.json`（脏标记 + 离开确认）；[EntityStore](../../storage/EntityStore/EntityStore.h) 维护 `entities.json`；[CreateEntityDialog](../../WorkPlaces/DesignPaper/CreateEntityDialog.h) 新建/编辑实体；顶部展示"当前生效约定"（作品约定优先于全局，规则实现在 [StorySetup.h](../../models/StorySetup.h) 的 `effectiveWritingConvention()`）。
- 信号出口：`locateEntityInGraphRequested(entityId)` → MainWin 转图谱页并定位节点。

### 4. 关系图谱页 [Relater](../../WorkPlaces/RelationPaper/Relater.h)（RelationPaper/）

- `QGraphicsScene/View` 上的圆点-连线图：
  - 节点 `QGraphicsEllipseItem` 可拖动；`motionTimer_`（16ms）计算弹簧力 + 节点排斥 + 阻尼，实现"拖动邻居被牵动、松手回弹"的物理动画；`nodeVelocities_`/`settledFrames_` 控制停稳。
  - 初始布局用黄金角铺开 + 关系力修正；同一作品会话内保留已拖动位置（**坐标暂未持久化**，为已知待办）。
- 关系维护：[CreateRelationshipDialog](../../WorkPlaces/RelationPaper/CreateRelationshipDialog.h) 双向称呼 + 备注；点击节点高亮相邻并只在右侧检查器显示"当前节点视角"的称呼。
- 搜索：按资料名过滤 → 选择结果 → `locateEntityById()` 平移视图居中。

### 5. 设置页 [Setter](../../WorkPlaces/SettingPaper/Setter.h)（SettingPaper/）

分节管理本机全局设置（注意：均为**本机设置**，与单部作品的设定相互独立）：

| 分节 | 存储位置 | 说明 |
| --- | --- | --- |
| 作者资料 | QSettings（INI） | 默认笔名 + 圆形头像 `author-avatar.png` |
| 全局写作约定 | [GlobalWritingConventionStore](../../storage/GlobalWritingConventionStore.h) | 作品约定全空时的兜底 |
| 行内建议开关 | [InlineSuggestionSettings](../../storage/InlineSuggestionSettings.h) | 总开关，同步给 WriterWorkspace |
| **模型与提示** | 多个 Store（见下） | Ollama / 云端双源配置、测试、激活、请求记录 |

模型分节职责：

- 服务源切换（`modelSourceStack_`）：本地 Ollama ↔ 云端服务，`ActiveModelServiceStore` 记录当前选择。
- Ollama：地址校验（`ModelSettingsStore::validate`）、`/api/tags` 拉取已装模型、测试连接、增删已知模型。
- 云端：多条 [CloudProfile](../../storage/CloudProfileStore.h) 配置（预设模板：DeepSeek/百炼/OpenAI/自定义）、API Key 存取（Windows 凭据管理器）、测试、激活。
- 系统提示词编辑：`systemPromptEdit_` 读写 `InlinePromptSettingsStore`，可恢复默认。
- [ModelDebugDialog](../../WorkPlaces/SettingPaper/ModelDebugDialog.h)："查看请求记录"，展示 [ModelRequestLog](../../WorkPlaces/Generation/ModelRequestLog.h) 中本次运行的请求/响应 JSON。

## AI 服务层（概要）

位于 [WorkPlaces/Generation/](../../WorkPlaces/Generation/GenerationService.h) 与 [WorkPlaces/ContextBuilder/](../../WorkPlaces/ContextBuilder/ContextBuilder.h)：

- `GenerationService`：抽象基类（`start/cancel` + 三个信号）。
- `RoutedGenerationService`：按激活身份分发到 Ollama / 云端实现，并转发可用性状态。
- `OllamaGenerationService`：`POST /api/generate`，本地模型用 JSON Schema 约束输出。
- `CloudGenerationService` + `CloudChatApi`：OpenAI 兼容 `POST /chat/completions`。
- `InlinePrompt`：指令与系统提示词模板、长度常量。
- `ContextBuilder`：把作品资料 + 章节正文组装为上下文（预览版 / 行内建议版两种）。
- `InlineSuggestionFilter`：回复清洗与拒绝。
- `ModelRequestLog`：内存环形请求日志（最多 30 条，不落盘）。
- `MockGenerationService`：固定输出"微微一沉"的测试桩。

**完整链路、提示词内容、重试与安全设计 → [03-AI行内建议子系统](03-AI行内建议子系统.md)。**

## 存储层（概要）

全部为无状态静态函数的 Store 类，详见 [04-数据模型与存储](04-数据模型与存储.md)：

- 路径常量统一在 [StoragePaths.h](../../storage/StoragePaths.h)；[AppSettings.h](../../storage/AppSettings.h) 提供唯一的 QSettings 入口。
- 作品库级：`ProjectStore`、`ChapterStore`（+ `.bak`）、`DocumentImporter`、`DataRootStore`/`DataRootMigration`（整库迁移三步：校验→复制→验证）。
- 本机设置级：模型相关 5 个 Store + 全局约定 + 作者资料，全部落在 QSettings INI；唯一例外是 API Key 走 Windows 凭据管理器。

## 信号同步一览

| 信号 | 起点 → 终点 | 用途 |
| --- | --- | --- |
| `Paper::openProjectRequested(id)` | Paper → MainWin → WriterWorkspace | 打开作品 |
| `WriterWorkspace::currentProjectChanged(id)` | Workspace → MainWin → designer/Relater | 设定页与图谱跟随当前作品 |
| `Paper::projectInfoChanged(Project)` | Paper → MainWin → Workspace | 作品库改名/编辑后同步已打开标签 |
| `Setter::globalWritingConventionChanged` | Setter → MainWin → designer | 全局约定变化刷新"当前生效约定" |
| `Setter::inlineSuggestionEnabledChanged(bool)` | Setter → Workspace → Writer | AI 建议总开关 |
| `Setter::activeModelChanged / modelAvailabilityChanged` | Setter/Writer → MainWin | 顶部模型徽标 |
| `designer::locateEntityInGraphRequested(id)` | designer → MainWin → Relater | 跳转图谱并定位 |
| `GenerationService::generated/failed/availabilityChanged` | 服务 → Writer → MainWin | AI 结果与状态 |
